# Hossam Hassan Mohamed — Junior Penetration Tester Portfolio

A modern, responsive offensive security portfolio showcasing penetration testing methodologies, engagements, CTF track record, certifications, and technical capabilities.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Fonts**: JetBrains Mono, Inter

## Getting Started

### Prerequisites

- Node.js 18.17+ or later
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Y4t0x1/hossam-portfolio.git

# Navigate to project directory
cd hossam-portfolio

# Install dependencies
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

### Build

Create an optimized production build:

```bash
npm run build
```

Run typechecking:

```bash
npm run typecheck
```
